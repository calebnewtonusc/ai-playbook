# Level 5: get a real tool built for you

Some jobs need a real tool: a contact list that tells you who you haven't talked to in a month, a page for an event, an agent that searches for grants every week. You don't need to code to get one. You need to be good at saying what you want.

## What the AI does

[Claude Code](https://claude.com/claude-code) builds it, saves it to GitHub, and puts it on the internet. [Guide steps 1 to 3](../guide/01-tools.md) set it up and walk through a first project. Someone who knows the setup can do the install with you in half an hour.

## What you keep doing

You write the spec. That's the most important part of any build, and it's all plain English. Make a file called `SPEC.md`:

- **Who it's for.** One real person, by name.
- **The one thing they do with it.** One, not five.
- **What it must never do.** Especially with people's private information.
- **What done looks like.** How you'll know it works.

Then:

```text
Read SPEC.md. Ask me questions until it's right. Then give me a 5 bullet
plan and wait for my go. Build one small slice, run it, and show me it
working before you do the next one. Save every working step to GitHub.
```

You decide every fork. You look at every slice. You say "that's wrong" as often as you need to. [The loop](../guide/04-the-loop.md) is the whole method.

## Checkpoint

A tool you use every week, built by Claude Code from a spec you wrote. You can explain in two sentences what it does and where your data lives.

From here, the [builder track](../track/README.md) goes deeper if you want it.
