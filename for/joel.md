# For Joel

Dad, this is the setup I've been telling you about, written so you can go at your own pace and come back to it. You don't have to code and you don't have to learn GitHub. Claude handles all of that. Your job is the part only you can do: knowing what you want and saying it clearly.

Text me if you get stuck, or just call and we'll do it together.

## What you told me you want

- A setup like the one-person, one-agent company you sent me, where Claude runs real parts of the work
- Your own CRM, built around your network, that you can talk to
- An agent that finds scholarships and grants and drafts the applications
- The ads and the repeat stuff a lot more automated

All of that is doable. The order matters, because each step makes the next one work.

## Your path

1. [Start without code](../guide/00-start-without-code.md). Set up a Project called Joel Newton and let Claude interview you for the About me doc. Do it by voice. This is the most important hour.
2. [Level 0: stay the thinker](../track/00-stay-the-engineer.md). Ten minutes. The habits that keep AI making you sharper.
3. [Everyday levels 1 to 4](../everyday/README.md). A Claude that knows you, one chore handed off, catching it when it's wrong, then your email and calendar connected.
4. [Everyday level 5](../everyday/level-5-get-it-built.md). This is where the CRM and the grants agent get built. We'll do the Claude Code install together, and you write the spec by talking it out.

## Your questions, answered

**Do I need an always-on computer?** Not to start. Your laptop does everything through level 5. The office PC only matters later, for jobs that run on a schedule while you sleep, like a morning brief that's waiting when you wake up.

**Is Pro enough?** To start, yes. Claude Code on Pro runs out faster than on Max, so if you're hitting the limit every week once you're building, that's when Max is worth it.

**What's GitHub and do I need it?** It's like Google Drive for projects: it keeps every version of everything Claude builds, so nothing is ever lost. You'll never type a GitHub command. Claude Code saves your work there when you say "save this."

## Your first real project

Pick one weekly chore you'd love to never do again and hand it off at [everyday level 2](../everyday/level-2-hand-off-a-chore.md). Small and done beats big and half-built.
