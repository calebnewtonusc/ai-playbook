# AGENTS.md

Rules for any AI (Claude Code, Codex, Cursor) working in this repo.

## What this is

A start-from-zero playbook for working with AI, written so people get sharper from it, not more dependent. The body is general. Pages in `for/` are short front pages for specific people, saying where they start.

## Map

- `README.md`: the start page, with the two paths
- `for/`: per-person front pages. Read the reader's page first if they name themselves
- `guide/00-08`: getting started, in order. Step 0 is the no-code start
- `everyday/`: the no-code track, levels 1 to 5
- `track/`: the builder (AI-native engineer) track, levels 0 to 5. Level 0 is shared
- `kit/`: a starter Claude Code setup (rules, hooks, skills, agents) for builder level 4
- `prompts/README.md`: copy-paste prompts
- `templates/CLAUDE.md`: the rules file a builder copies into their own projects
- `skills/coach-me/SKILL.md`: how to coach someone through this

## When someone asks for help

Follow `skills/coach-me/SKILL.md`. Find out who they are and which step they're on, then go one action at a time.

## When editing this repo

- Keep the body general. A person's name, goals and details go only in their `for/` page.
- Keep the plain-English, beginner-first tone. Explain every command in one line.
- No em dashes, no emojis outside the README footer, no hype words.
- Facts in the case studies come from the real project's git history and docs. Don't invent prompts and present them as exact words.
- Never add anyone's phone number, email, home address, file paths from a personal machine, or private details. Public repo.
